Each entry records: the step, the command, what I expected, what actually happened (exact error), what I tried next (docs page, search or AI prompt), and whether it was resolved. Where I could not verify something, the entry says so.

## F1: `swy auth status` printed "No connected accounts" after sign-in

- **Step**: Checking authentication status after `swy init`
- **Command/action**: `swy auth status`
- **Expected**: A signed-in confirmation (the init banner had shown my email)
- **Actual with exact error**: "No connected accounts. Run `swytchcode auth connect <provider>`."
- **Tried next with docs page/heading/search/AI prompt**: From the CLI behaviour I inferred that `swy login` signs in to Swytchcode, while `swy auth connect <provider>` links a provider account such as GitHub, so "connected accounts" means provider connections. I found no official docs page confirming this, so it is an inference.
- **Resolved yes/no**: Yes (understood, but based on inference, not documentation)
